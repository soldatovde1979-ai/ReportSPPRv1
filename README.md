# ReportSPPR — еженедельный отчёт о качестве 1С-поддержки

**Запуск:** [![Открыть в Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/soldatovde1979-ai/ReportSPPRv1/blob/main/RepSSPR_v5.2.ipynb) — ноутбук `RepSSPR_v5.2.ipynb`

Единый вход: эта страница (`github.com/soldatovde1979-ai/ReportSPPRv1`) — её адрес не меняется, кнопка ведёт на текущую версию ноутбука. Продуктив = ветка `main`: ноутбук открывается с GitHub, модуль и шаблон он скачивает с GitHub сам (`docs/my-FT.md`, Р-10).

Как запускать:
1. Нажать кнопку выше; в Colab — секрет `DEEPSEEK_API_KEY` (или `GEMINI_API_KEY`).
2. «Среда выполнения → Выполнить всё», в окне загрузки — выгрузка `sppr_dump_*.json`.
3. После ячейки 1 — строка `🧩 Модуль report_v5.py … (GitHub)`; «(запасная копия)» — GitHub недоступен, взята копия с Диска.

Подробно: `HANDOFF.md`, разд. 5, п. 4; что за система — `docs/spec.md`; правила для ИИ — `CLAUDE.md`.
